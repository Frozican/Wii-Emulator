No-copy disc range-read test

This isolated test checks whether your browser can read selected disc-file ranges asynchronously without first copying the entire file into browser storage.

What this test does and does not prove

It sends the selected browser File object to a dedicated worker and reads small byte ranges from the beginning, quarter points, midpoint, and end. It does not create a full OPFS copy and does not upload the file.

A PASS proves only that asynchronous range reads work in this browser. Gecko currently expects synchronous disc reads from memory, so this test alone does not make the emulator stream a game. Integrating range reads still requires changes to the emulator's disc-read architecture.

Keep the original file where it is. Browser permissions or Android file-provider restrictions may still prevent reading some files.
