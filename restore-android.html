Restore NKit
on Android.

GitHub Pages cannot run a native multi-gigabyte restore process itself. This route runs the real open-source nkit2iso tool locally in Termux, then you can select the restored ISO in the experimental emulator.

Install Termux from official releases ↗
Storage warning
Your 3.39 GB NKit file may restore to a roughly 4.7 GB ISO. Make sure you have at least 6 GB free. Do not delete the original file. This may take a while on a phone.

1. Give Termux file access and install tools

Open Termux, paste this command, and approve Android's file-access prompt.

termux-setup-storage
pkg update
pkg upgrade
pkg install git golang

2. Download and compile nkit2iso locally

This builds the converter on your device. Current nkit2iso source requires Go 1.24 or newer; if the build says your Go version is too old, update Termux packages and retry.

cd ~
git clone https://github.com/DonMikone/nkit2iso.git
cd nkit2iso
go version
go build -o nkit2iso .

3. Restore the game file

This example assumes the file is in your phone's Download folder and has the filename shown below. If your filename or folder differs, edit both paths to match exactly.

~/nkit2iso/nkit2iso -i "$HOME/storage/shared/Download/Super Mario Galaxy (USA) (En,Fr,Es).nkit.iso" -o "$HOME/storage/shared/Download/Super Mario Galaxy (USA) (En,Fr,Es).iso"

4. Check the result

Wait for the process to finish. A successful bit-exact restore reports a CRC32 match. If it reports an error or CRC mismatch, do not use the output; keep the original NKit file.

Some NKit files have a removed Wii update partition that cannot be reconstructed from the image alone. The tool reports this limitation rather than pretending the data is present.

Then open the experimental emulator and choose the restored .iso file. The emulator itself is still experimental and may not boot the game yet.
