FIRST ENGINE INTEGRATION

Try the Gecko WebAssembly build

This experimental build wires Gecko's Wii disc boot path for restored Wii ISO/RVZ images. NKit images are not restored by the browser build and cannot boot yet. A successful launch attempt is not proof of playable gameplay; the first goal is to capture the exact boot/apploader result. Large images may exceed browser memory, especially on phones.

IMAGE PREPARATION

Restore an NKit Wii image

Choose your own .nkit.iso to check it locally before restoration. The selected file is never uploaded. Full restoration is not yet implemented in this browser page; this checker will not create or rename a fake ISO.

Need the actual conversion?
Use the open-source NKit2 desktop tool or nkit2iso. After converting your own image to a regular ISO or RVZ, return here and try the experimental engine. The browser converter is not ready yet.

Test disc-file reading
