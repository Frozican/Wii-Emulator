FIRST ENGINE INTEGRATION

Try the Gecko WebAssembly build

This experimental build uses the open-source Gecko emulator engine. Its current browser entry point accepts DOL homebrew executables or IPL files. It does not yet boot Wii ISO/RVZ disc images, and mobile touch controls are not connected.
