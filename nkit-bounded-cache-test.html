NKit bounded range-cache prototype

This is a browser I/O prototype, not the emulator. It reads a few known FST files through a fixed-size LRU cache over File.slice(), checks cache hits, cross-chunk reads, and the memory bound. The complete ISO and complete files are never copied.


Choose the ISO, then run the test.

Prototype parameters: 256 KiB chunks, 4 MiB maximum cached payload. A passing result validates this JS cache only; it does not connect the cache to Gecko's synchronous Dvd trait.
