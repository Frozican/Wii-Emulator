Wii Sector Reader Prototype

Local diagnostic prototype. Select your own Wii/NKit ISO; it reads only the disc header, partition metadata, and first 32 KiB partition sector in a Worker. It does not upload the file or copy the ISO into browser storage.

Choose an ISO file to begin.

This is a sector/decryption diagnostic only. It does not locate the full FST, load the apploader, or boot the game. NKit layouts may require additional handling.
